Опыт работы

Ведущий инженер (разработка сервисов на Python) 08.2023 - настоящее время (3 года 2 месяца)
ПАО «МегаФон», телекоммуникации · удалённо

Команда эксплуатации корпоративного хранилища данных. Разрабатываю внутренние сервисы контроля качества данных для аналитиков и дежурной смены поверх Oracle DWH и Greenplum.

  • Сервис прогноза готовности витрин данных (Django, Celery, PostgreSQL). Спроектировал и разработал с нуля: сбор истории планировщика из Oracle (около 270 задач, граф из 68 тыс. связей), статистическая модель на квантилях с учётом календаря и зависимостей задач, уточнение прогноза по фактам текущего дня. Средняя ошибка в продуктиве 33 минуты против 123 у оценки по исторической норме.
  • Вёл задачу от постановки до внедрения: собрал требования с дежурной сменой и аналитиками, оформил архитектурное решение (ADR), представил результат на докладе.
  • Выстроил контроль качества модели: бэктест на исторических данных с метриками MAE и покрытием p90, около 170 юнит-тестов. Изменения логики прогноза принимаются только по результатам бэктеста.
  • Портал контроля качества данных (Django REST Framework, React, Redux): проверки дашбордов и KPI, HTML-рассылки по итогам, SSO через Keycloak (JWT), доступ по группам Active Directory (LDAP). Портал заменил ручные сверки показателей через SQL и почту.
  • Фоновые задачи на Celery с брокером RabbitMQ, расписание в Redis (redbeat), идемпотентная обработка под повторную доставку задач. Сервисы работают в Kubernetes, сборка Docker-образов и CI/CD.
  • Интеграция с корпоративным хранилищем: Django ORM поверх легаси-схемы Oracle, несколько баз в одном проекте (PostgreSQL, Oracle, Greenplum), загрузка справочников из CSV с нечётким сопоставлением записей.
  • Провёл код-ревью портала и составил план рефакторинга по приоритетам. Разбирал инциденты ETL-потоков (Oracle, ODI, PL/SQL) до первопричины.

Опыт

Python-разработчик август 2023 — настоящее время
МегаФон · телекоммуникации · удалённо

Внутренние веб-сервисы для аналитиков и дежурной смены: портал контроля качества данных на Django REST + React и подсистема прогноза готовности витрин. Портал заменил ручные проверки через SQL и почту единым интерфейсом с автосопоставлением показателей и email-отчётами. Источник данных — корпоративное хранилище на Oracle DWH.

  • Бэкенд портала на Django REST Framework: сервисный слой, dataclass-DTO на границах слоёв, доменные исключения с единой картой в HTTP-статусы, разграничение доступа по группам Active Directory, SSO через Keycloak.
  • SPA на React + Redux: проверки, KPI, агрегаты, прогноз готовности. Задачу веду целиком, и бэкенд, и фронт.
  • Сервис прогноза готовности витрин. Ночной сбор истории планировщика в PostgreSQL через Celery, квантильная модель с учётом календарных режимов и зависимостей задач, уточнение фактами текущего дня. Бэктест: MAE 26 минут против 90 у наивной оценки, покрытие p90 ≈ 89 %.
  • Загрузка справочника KPI из CSV с нечётким сопоставлением записей и автоматическим разбором на создание, обновление и закрытие показателей. Заменила ручную сверку файлов аналитиками.
  • Django ORM поверх легаси-схемы Oracle: несколько алиасов баз данных, read-only модели над существующими таблицами.
  • Инциденты продуктивных ETL-потоков (Oracle, ODI, PL/SQL) — разбор до причины: кодировки, региональные настройки базы, дубли SCD Type 2, зависшие сессии.
  • Код-ревью кодовой базы с приоритизацией находок и планом устранения.
